# เป้กไหม · สำรับจั่วออนไลน์

เกมไพ่ปาร์ตี้ "เป้กไหม" เวอร์ชันจั่วออนไลน์ เพื่อนเปิดลิงก์เดียวกันแล้วเห็นการ์ดที่เปิดพร้อมกัน ไม่ต้องล็อกอิน

- `public/` หน้าเว็บ (HTML + `app.js`) ให้บริการผ่าน Workers Static Assets
- `src/index.js` Worker + Durable Object `Room` หนึ่งห้องต่อหนึ่งรหัส ถือสถานะสำรับและสับ/จั่วฝั่งเซิร์ฟเวอร์ (กันสองคนจั่วชนกัน) ส่งสถานะผ่าน WebSocket
- จำนวนใบของแต่ละแบบตั้งได้ในหน้าเกม (ค่าเริ่มต้นแบบละ 2 ใบ การ์ดหายากใบละ 1) มีผลเมื่อกดสับสำรับใหม่

## รันบนเครื่อง

```
npm install
npm run dev        # http://127.0.0.1:8787
```

## Deploy

```
npx wrangler login
npm run deploy
```

ใช้แพ็กเกจฟรีได้ (Durable Object แบบ SQLite) ไม่มี secret หรือข้อมูลส่วนตัวในโค้ด

## ส่งลิงก์ให้เพื่อน

เปิดหน้าเกม ระบบสุ่มรหัสห้อง 4 ตัวให้ แล้วกด "คัดลอกลิงก์ห้อง" ส่งต่อได้เลย
